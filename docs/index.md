# selectize.js documentation

Selectize is a jQuery-based control for turning text inputs and select elements into searchable, taggable single- or multi-value inputs.

## Start here

1. Read [Getting Started](docs/intro.mdx) to install Selectize and its browser dependencies.
2. Follow the [Usage guide](docs/usage.mdx) for initialization and configuration.
3. Consult the [API reference](docs/api.mdx) for programmatic control.
